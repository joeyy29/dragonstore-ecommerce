🛒DragonStone E-Commerce

A lightweight PHP + MySQL e-commerce platform built for learning and experimenttion.
DragonStone lets users browse products, manage shopping carts, and complete secure orders, while admins handle product management and report via a simple dashboard.

Features✨

User authentication (sign up / sign in)
Product catalog with filtering
Shopping cart and checkout flow
Order tracking and admin reporting
MySQL-backed product and user management

⚙️Tech Stack

Backend: PHP, MySQL
Frontend: HTML, CSS, JavaScript
Version Control: GitHub
